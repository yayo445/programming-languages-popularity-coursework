# Інструкція зі створення інтерактивної аналітичної панелі в Tableau Public

Цей каталог містить підготовлені та очищені дані, згенеровані скриптом `src/analysis_pipeline.py` для виконання розділу **4.7 методичних рекомендацій** (створення інтерактивного дашборду в Tableau Public).

## 1. Підготовлені файли даних
1. **`tableau_coursework_data.xlsx`** *(рекомендовано для швидкого імпорту)* — книга Excel із двома аркушами:
   - `Quarterly_By_Country` — поквартальна динаміка (2020 Q1 – 2026 Q2) по Топ-35 мовах і всіх країнах (включно з Україною `UA`), з показниками `num_pushers`, `developers`, `repositories`, `pushers_per_1000_devs`, `language_share_pct`, `language_era`, `dev_market_tier`, `macro_region`.
   - `Language_Summary_PLDB` — зведений профіль мов на 2026 Q2 із показниками PLDB (`appeared`, `pldbScore`, `numberOfUsersEstimate`, `numberOfJobsEstimate`, `bookCount`, `growth_multiple`).
2. **`tableau_languages_main.csv`** і **`tableau_language_summary.csv`** — альтернативні CSV-версії тих самих таблиць.

---

## 2. Покрокове створення дашборду у Tableau Public

### Крок 1. Імпорт даних
1. Відкрийте **Tableau Public** (Desktop або Web Authoring на [public.tableau.com](https://public.tableau.com/)).
2. Оберіть **Connect → Microsoft Excel** і відкрийте файл `tableau_coursework_data.xlsx`.
3. Перетягніть аркуш `Quarterly_By_Country` на область полотна (Data Source).

### Крок 2. Створення 4 робочих аркушів (Worksheets)
*(За методичними рекомендаціями потрібно щонайменше 3 аркуші з різними візуалізаціями та ключові показники KPI).*

1. **Аркуш 1 — `KPI Огляд` (Ключові показники)**:
   - Створіть обчислені поля або використайте:
     - `SUM(num_pushers)` (формат: млн/тис.) — сумарна кількість активних розробників;
     - `COUNTD(language)` — кількість проаналізованих мов;
     - `COUNTD(iso2_code)` — кількість країн;
     - `AVG(pushers_per_1000_devs)` — середня інтенсивність використання на 1000 розробників.
   - Виведіть ці 4 метрики великим шрифтом (Text / BANs — Big Ass Numbers).

2. **Аркуш 2 — `Динаміка мов` (Лінійний графік)**:
   - **Columns**: `Period Date` (виберіть безперервний квартал *Quarter Continuous* або `Period Label`).
   - **Rows**: `SUM(num_pushers)`.
   - **Color**: `Language` (у фільтрі залиште 8–10 провідних мов, наприклад `JavaScript`, `Python`, `TypeScript`, `Java`, `C++`, `C`, `PHP`, `C#`, `Go`, `Rust`).
   - Увімкніть підписи кінців ліній (Mark Labels → Line Ends).

3. **Аркуш 3 — `Географія розробників` (Хороплетна карта або Топ-15 країн)**:
   - **Варіант карти (рекомендовано)**: перетягніть `Iso2 Code` (призначте Geographic Role → Country/Region) на полотно, **Color**: `SUM(num_pushers)` або `AVG(pushers_per_1000_devs)`, **Tooltip**: додайте `Country Name Uk`, `SUM(developers)`, `SUM(repositories)`.
   - Або горизонтальна стовпчикова діаграма по `Country Name Uk` з виділенням України (`UA`).

4. **Аркуш 4 — `Рейтинг мов і покоління` (Стовпчикова діаграма / Scatter)**:
   - **Rows**: `Language` (сортування за спаданням `SUM(num_pushers)`).
   - **Columns**: `SUM(num_pushers)`.
   - **Color**: `Language Era` (покоління появи мови) або `Language Type`.
   - Задайте фільтр за останнім періодом (`Period Label = 2026-Q2`) або додайте у загальний фільтр дашборду.

### Крок 3. Збирання Дашборду (Dashboard) та інтерактивних елементів
1. Створіть новий **Dashboard** (розмір `Desktop Browser 1200×800` або `Automatic`).
2. Додайте назву зверху: *«Аналітична панель: Популярність мов програмування у світі та Україні (GitHub, 2020–2026)»*.
3. Розмістіть зверху блок `KPI Огляд`, нижче у два ряди або 2×2 — аркуші `Динаміка мов`, `Географія розробників` і `Рейтинг мов і покоління`.
4. Додайте **щонайменше 3 інтерактивні фільтри** (Apply to Worksheets → All Using This Data Source):
   - **Фільтр 1**: `Country Name Uk` (або `Macro Region`) — можливість обрати, наприклад, *Україна*, *США*, *Німеччина* або *Усі країни*;
   - **Фільтр 2**: `Period Label` (або `Year`) — слайдер чи список періодів `2020-Q1` — `2026-Q2`;
   - **Фільтр 3**: `Language Type` / `Is General Purpose` — перемикання між загальнопризначеними мовами та утилітами (`Shell`, `Dockerfile` тощо).
5. Увімкніть на аркуші `Географія розробників` і `Рейтинг мов` режим **Use as Filter** (клік по країні або мові інтерактивно фільтрує інші графіки).

### Крок 4. Публікація та вставка у курсову роботу
1. Натисніть **File → Save to Tableau Public** і скопіюйте отримане публічне посилання (`https://public.tableau.com/views/...`).
2. Зробіть чіткий скриншот усього дашборду (де видно заголовок, KPI, 3+ графіки та інтерактивні фільтри), збережіть його як `tableau/dashboard_screenshot.png`.
3. Відкрийте `Пояснювальна_записка_Литвин_401ТН.docx`, перейдіть до **підрозділу 4.2** і в спеціально виділений блок:
   - вставте посилання на опублікований дашборд;
   - вставте збережений скриншот замість рамки для **Рисунка 4.9**.
